# -----------------------------------------------------------------------------
# Windows native-runtime requirements that pip cannot supply
# -----------------------------------------------------------------------------
# These are still required for complete functionality on Windows:
#
# 1. Tesseract OCR for pytesseract:
#      Install a Windows Tesseract distribution, then set TESSERACT_CMD when
#      tesseract.exe is not on PATH. Install language data for every declared
#      language: eng, heb, and ara. Missing language data is a retryable OCR
#      failure; it must not be silently replaced with English.
#
# 2. UnRAR.exe or bsdtar.exe for rarfile:
#      Install a Windows build and put it on PATH, or configure rarfile's
#      executable path. py7zr does not replace the external RAR requirement.
#
# 3. FFmpeg.exe for moviepy and video readers:
#      Install a Windows FFmpeg build, put ffmpeg.exe/ffprobe.exe on PATH, or
#      configure the application's FFmpeg path. This is required for media
#      formats that MoviePy delegates to FFmpeg.
#
# 4. PostgreSQL server:
#      Install a supported Windows PostgreSQL server and create/configure the
#      application's database. psycopg2-binary is only the client driver.
#
# 5. PST/libpff support:
#      libpff/libpff-python is not guaranteed to have native Windows wheels.
#      Treat PST support as unavailable until the pypff import and a real PST
#      extraction test pass on the target Windows installation; preserve the
#      file record and report the dependency failure otherwise.
#
# [WIN-BINARY] packages above are native Windows wheels, not Unix-only
# packages. Pin versions for production after testing the chosen CPython
# version, because wheel availability varies by Python release and CPU arch.
