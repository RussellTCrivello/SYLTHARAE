{# component: record_actions purpose: The actions a single record offers. The buttons come from the Action Definition layer - id, label, icon, scope, destructiveness, confirmation key - joined with the screen's own bindings by core/experience/presentation.py, so a page cannot invent an action and two pages cannot render one action two ways. inputs: actions (the grouped payload from presentation.record_actions: primary, secondary, overflow, hidden, skipped), surface_id, label (the accessible name of the toolbar), busy_label outputs: none. The component performs nothing. events: a click on a [data-record-action] element is handled by the page through static/js/modules/core/record-actions.js, which asks the Confirmation Dialog when the action declares one, marks the control busy, and reports the outcome through the Toast. states: normal, loading, success, error, unauthorized presentation_states: neutral, danger slots: primary, secondary and overflow groups accessibility: role="toolbar" with an accessible name; a navigation is a link and an operation is a button, so the keyboard and the middle click behave as the reader expects; a disabled action stays in the DOM with aria-disabled and a reason in its accessible description; a dangerous action's name is its label, and the confirmation is where the risk is spelled out; busy state sets aria-busy and keeps the label rather than replacing it with an icon. third_party: Bootstrap 5 buttons and dropdown for the overflow menu. css: btn-action, btn-danger, btn-outline-secondary, dropdown-menu, record-actions - from the stylesheet this project already ships. notes: `disabled` and `hidden` belong to an action, not to this component: an action that cannot be used right now keeps its place with `aria-disabled` and a reason (a missing original file, an archived record), and an action that must not be shown is not rendered at all. Both are facts the surface was handed, and neither is a security boundary - the endpoint decides on its own, every time. boundary: it draws what the registry and the screen agreed on.
