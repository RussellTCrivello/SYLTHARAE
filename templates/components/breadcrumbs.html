{# component: breadcrumbs purpose: Where the reader is, rendered from the interface registry: a page says what it is about, the registry supplies the words and icons. states: normal classes: breadcrumb, breadcrumb-item, active notes: No page supplies a breadcrumb label or icon map; if a label is missing the registry does not know that page, which the coverage test reports. #} {# ========================================================================== Breadcrumbs. A page passes *what it is about* - a parent list and the record it is showing - and this component supplies the labels and icons from the registry. Pages used to write the whole trail by hand, which duplicated product names and icons in markup ("Sources" with bi-building here, a different icon there) and drifted from the registry silently. Usage: {% from 'components/breadcrumbs.html' import breadcrumbs %} {% block breadcrumb %}{{ breadcrumbs(parent='sources_list') }}{% endblock %} {% block breadcrumb %}{{ breadcrumbs(parent='sides_list', intermediate=[{'label': side.name, 'url': url_for('side_detail', side_id=side.id)}], current=_('Categories & Keywords')) }}{% endblock %} `interface_for(endpoint)` is prepared by the application context; it returns the registry's own label and icon for a route, so a component never invents a product name. ========================================================================== #} {% macro breadcrumbs(parent=None, intermediate=(), current=None) %} {% set home_label = _('Home') %}
