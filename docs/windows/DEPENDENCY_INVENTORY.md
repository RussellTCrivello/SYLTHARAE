# Windows offline dependency inventory

Generated by `tools/windows/inventory_dependencies.py` from `requirements.txt` and `pyproject.toml`; regenerate and commit whenever a dependency changes (a test fails on a stale copy).

Every dependency required for normal operation on a native, offline Windows machine is provisioned locally by the offline bundle (`tools/windows/build_offline_bundle.py`). Nothing here downloads at runtime: Tesseract reads only its local tessdata; RapidOCR reads only the models bundled in its wheel; the web interface serves only vendored scripts, styles and fonts.

## Native Windows binaries

| Component | Form | Purpose | Required | Bundle stage |
|---|---|---|---|---|
| Tesseract OCR 5.x (UB-Mannheim portable build) | x64 portable zip | primary OCR engine; no installer, no registry, no network | required | tesseract |
| FFmpeg (gyan.dev release build) | x64 shared/freeless zip | video decoding for the OpenCV media path; without it media files are recorded as unsupported instead of failing the deployment | optional (media formats) | tesseract |

## Database

| Component | Form | Provisioning |
|---|---|---|
| PostgreSQL 16 (server, initdb, client tools) | binaries inside the `pgserver` wheel | `wheels` stage; a private cluster is created under the data directory by `tools/windows/local_postgres.py` — no service, no EDB installer, no network |
| psycopg2-binary | client wheel | `wheels` stage |

PostgreSQL stays: the data model, migrations and full-text behaviour are PostgreSQL's. The bundle does not replace it with an embedded database; it ships one.

## OCR engines and language data

| Item | Source | Offline behaviour |
|---|---|---|
| Tesseract (primary engine) | `tesseract` stage (portable build) | reads only `TESSDATA_PREFIX`; never downloads |
| eng / ara / heb language data | `offline-bundle/windows/tessdata` (tessdata_fast), hashes in `MANIFEST.sha256` | installed into the bundled tessdata directory |
| RapidOCR (fallback engine) | `rapidocr-onnxruntime` wheel | PP-OCRv4 models are inside the wheel; load is local; a missing language is reported, not substituted |

## Browser and static assets

- No browser, driver or Node.js is required at runtime: the interface is server-rendered HTML with vendored JavaScript, CSS, Bootstrap Icons and the Inter / Noto Sans Arabic fonts.
- `tests/unit/test_no_remote_runtime_resources.py` fails if a template, stylesheet or script references a remote resource, so a CDN link cannot return silently.
- puppeteer-core + a Chromium build are development-only (browser smoke test) and never ship in the bundle.

## Development-only dependencies (not shipped)

- pytest
- pytest-cov
- ruff
- bandit
- pyzipper
- pip-audit
- puppeteer-core (browser smoke tooling; not a Python dependency)

## External/network integrations (opt-in, off by default)

| Package | Purpose | Offline stance |
|---|---|---|
| sentry-sdk | error reporting; disabled unless a DSN is configured | EXCLUDE from offline operation: leave unconfigured |
| rollbar | error reporting; disabled unless a token is configured | EXCLUDE from offline operation: leave unconfigured |

Normal operation performs no outbound connections; `tools/windows/offline_acceptance.py` monitors and classifies connection attempts during the offline acceptance test.

## What the bundle must contain (release gate)

1. Python 3.11 Windows installer (pinned URL + SHA-256 in the bundle manifest).
2. The complete win_amd64 wheelhouse for the base requirements plus the runtime extras (`pip install --no-index` must succeed with nothing else present).
3. The Tesseract portable build and the eng/ara/heb tessdata.
4. The application source archive (`git archive` of the release commit).
5. `manifest.json` with a SHA-256 for every file; `build_offline_bundle.py --verify` re-checks it offline.
